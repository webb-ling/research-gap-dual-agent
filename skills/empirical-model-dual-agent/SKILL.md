# 实证模型建立与核验双 Agent Skill

输入为研究问题、上一环节的候选空白及核验记录、研究者初稿、官方数据文档；微观数据可选。保留初稿和每轮修改。主 Agent 填写[动态提示词](references/agent-prompts.md)，按实际工具连接情况分配任务；宿主不支持子 Agent 时依次运行两个独立角色，不声称并行。

## 建模与独立审查

1. 建模 Agent 核对数据说明、问卷跳题、变量含义和时间覆盖，提出分析单位、样本筛选、结局与解释变量编码、交互、控制变量、固定效应、缺失处理、估计目标、标准误、权重和稳健性方案。写出公式并定义符号。选择须由研究问题和数据结构支持。
2. 可用 `check_model_plan` 对照[方案结构](references/model-plan-schema.md)检查缺项和显见矛盾。返回 `ready_for_data_validation` 仅表示简单公式与必填字段通过静态核查；`requires_manual_review` 表示公式或抽样推断仍需独立复核；`data_validation_status=not_run`、`statistical_validity_status=not_assessed` 不能改写为“模型已验证”。
3. 检验 Agent 独立对照官方资料挑错，特别审查样本可比性、变量编码、混杂、模型族与结局类型、交互项解释、调查设计、标准误、识别假设和反例。按“问题—证据—影响—建议”输出，不直接修改建模稿。
4. 主 Agent 把意见逐条交给建模 Agent。建模 Agent 标注“采纳／不采纳／待数据验证”并说明理由；检验 Agent 复核关键修改。不能仅靠 `check_model_plan` 的通过状态结束审查。

## 有数据时的核查边界

仅在使用者明确提供本地 CSV，且启动 MCP 前已设置其授权目录 `RESEARCH_DATA_DIR` 时，可用 `profile_csv_variables`、`count_group_cells` 查看选定列的未加权缺失与分组分布。按代码本提供逐列缺失码；小于 `RESEARCH_MIN_CELL_COUNT` 的类别或单元格计数会被抑制。结果只涵盖检查的行，须查看 `truncated_by_row_limit`。工具不返回个人记录，不做加权估计、拟合回归或诊断。

如使用者另外提供数据和可用统计软件，才可另行执行真实模型估计，并由检验 Agent 对结果、标准误、模型诊断和稳健性做独立复核；报告须列明实际运行的软件、代码、样本和结果。仓库 MCP 当前只提供方案与描述统计辅助检查，不能声称已实现此步骤。

## 交付

交付初稿与修订稿对照、公式与符号、变量定义、样本与估计目标、每条审查意见的处理、实际使用工具、待数据验证项。无估计结果时称“拟议模型”或“待数据验证方案”，不编造系数、显著性或因果结论。
