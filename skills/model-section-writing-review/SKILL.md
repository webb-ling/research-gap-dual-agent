# 模型建立部分写作与三视角审阅

输入为研究者确认的模型、变量定义、数据来源、估计目标及本人撰写的模型建立部分初稿。先保存原稿。写作角色只依据已确认材料改善结构、定义和衔接；读者角色指出首次阅读时不明白的符号、样本或方法；编辑角色检查术语、公式、引用和主张是否与证据一致。若宿主支持子 Agent，可分配独立角色；否则依次执行并保留各自意见。

主 Agent 保存研究者原稿与写作角色第一稿，让读者和编辑分别提出独立意见；写作角色逐条标记“采纳／未采纳／待研究者确认”及理由并修订。读者和编辑再复核关键改动，主 Agent 核对每个符号与公式、数据事实与原始来源、研究局限与最终模型是否一致。缺少估计结果时，只写模型设定与计划的报告方法；不编造系数、显著性、样本量或文献。交付原稿与修订稿对照、读者和编辑意见、采纳记录及仍需研究者核对的问题。若用户要求直接编辑 Word 文档，使用当前环境可用的文档工具并检查最终排版。
