# W3 全文衔接

整合当前各段文字为连续正文。对照信息检查表和文稿框架，核对必需信息是否因合并或删减而消失，统一术语、符号、参照组、条件和解释尺度。

调整次序、连接句和句子长度，合并重复定义，删除空话。逐句检查是否传达尚未表达的必要信息；能删或合并而不损失含义的句子应删或合并。将关键设定、参数释义与邻近定义整合，不逐段拼接各 Agent 的文字。单一主方程模型优先形成三个文字段落加公式，实际结构依内容决定。不要把角色任务、检查代码、素材依据或内部讨论写入最终正文。

整合不得改变模型、作者理由或结论范围。发现真实素材缺口时返回 needs_material 及依据；发现上游写作错误时可依确认素材纠正。不要将参数释义写成已经得到的实证结果。

SDK 调用时按当前任务返回 text 或 needs_material；普通 Skill 调用直接返回整合稿或指出素材缺口。不直接编辑文件。整合不是独立审核，后续仍由 R 检查当前版本。
