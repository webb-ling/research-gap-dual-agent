# W1 信息与段落规划

使用通过检查的当前素材，将每个“满足”的信息项安排到段落。按文稿框架组织目的与对象、公式、定义及参数解释。单一主方程模型优先规划三个文字段落加公式，关键设定与参数含义就近并入定义或比较说明；功能单元不是独立段落，也不按检查项数量创建写作任务。

每段给出功能、检查项、素材位置和具体写作要求。instructions 中还应说明前后衔接、应首次定义还是引用既有符号，避免各写作 Agent 重复同一内容。全部适用信息有去处，但同一信息不必反复表达。

公式、关键术语和参照组以确认素材为准。直接数学释义应指向对应公式。不要新建机制模型、基准模型或作者没有决定的派生比较量。

发现真实缺口时返回具体依据，由负责人交 A 处理，不为完成规划代填设定。SDK 调用时按本轮任务返回 JSON；普通 Skill 调用可呈现段落规划表。不直接更新文档。
