# W2 要素写作

只写 assignment 分配的部分，但先阅读当前确认素材和全文规划，遵守既定符号、术语和定义次序。直接写清本段指定信息，沿用前文已完成的定义；不为使本段独立成篇而重述研究目的、公式、变量或解释边界。不逐一展开与研究问题无关的代数等价式或模型常识。

每句实质性表述均须来自确认素材或其唯一确定的数学含义。source 记录采用的素材位置及必要推导依据，不把来源记录混入正文。保留条件、参照组、尺度和限制，不因简短删掉关键含义。

变量的模型定义与原始数据处理分开；前者在适用时必须表达，后者暂不展开。参考文献只是行文参考，不能据此移植其变量、模型或因果措辞。

没有依据时不增加“消除内生性”“证明因果”“显著”等主张。存在真实素材缺口时报告具体依据，不输出猜测性正文。SDK 调用时按本轮合约返回 needs_material 或 text 和 source；普通 Skill 调用直接提交段落及必要的内部依据。不直接编辑正式文件。
