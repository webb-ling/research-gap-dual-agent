# 研究空白识别双 Agent Skill

输入为使用者的研究方向及研究对象、方法、数据等约束。主 Agent 根据当次输入制定检索式和工具分工，填写[动态提示词](references/agent-prompts.md)。若宿主支持子 Agent，可分别运行检索与核验角色；否则依次执行，分别保存输出，不声称实际并行。

## 配置与检索

1. 盘点当次真正可调用的网页、学术数据库、文件工具和 MCP。插件的 `search_literature` 同时查询 OpenAlex 与 Crossref 并合并当前页的重复书目；`search_openalex`、`search_crossref` 可分别查来源；`lookup_crossref_doi` 核对 DOI 元数据。工具不可用时使用当前可访问的原始网页，并记录替代途径。
2. 检索 Agent 将研究方向拆成同义词、邻近概念及可能推翻空白的反向检索式；至少检索宽、窄两组查询，并按需翻页。每次保存数据库、查询式、日期、页码、返回数量和实际筛读数量。接口的 `total_results_reported` 是数据库命中数，不是已筛读数；单页结果和相关性排序不能代表穷尽检索。跨查询、跨页去重后再整理文献。
3. 逐篇记录题名、完整作者信息、发表状态、DOI/原始链接、研究对象、数据、方法、关键结论和与拟议问题的重合点。对 `ambiguous_title_year_needs_review` 及 `metadata_conflicts` 逐条人工核对，不直接把合并结果当作准确引用。优先核对最接近研究；无法读到全文时，只转述摘要直接支持的内容。

## 独立核验与迭代

- 核验 Agent 将候选表视为待查材料。用 DOI 注册信息核对书目，再打开出版商页面或原文核查研究内容；用官方数据页面、问卷、代码本核查数据可行性。DOI 元数据相符不等于结论正确，Crossref 未收录不等于论文不存在。主动检索最可能推翻候选空白的研究。
- 对每项论断标记“通过／需修改／无法确认”，附来源和理由。主 Agent 将问题交回检索 Agent 补检，再请核验 Agent 复核关键修改。保留无法解决的分歧，不编造迭代轮次。
- 主 Agent 根据[研究空白交接结构](references/gap-evidence-schema.md)分别记录“已被研究的部分”“尚未直接回答的部分”“数据可行性”“证据边界”。可调用 `check_gap_evidence` 检查交接记录是否缺字段；该工具不核实链接内容或创新性。

## 交付

给出实际使用工具、检索式与筛读范围、去重后的文献对照表、独立核验记录、候选研究空白及未确认事项。只有在本轮范围内未见直接研究时，才写“本轮检索未见”；不得写成“尚无研究”。横截面关联与因果效应要区分。
