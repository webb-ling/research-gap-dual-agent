# 研究空白识别双 Agent Skill

使用者提供研究方向；可以补充研究对象、学科、研究类型、时间范围、语言、数据与方法限制。缺少非关键条件时，先作明确的工作假设并继续。若研究方向本身不明确，先请使用者给出主题。

## 配置与分工

1. 主 Agent 把方向拆成核心概念、同义词、相邻概念和可能推翻候选空白的反向检索词。记录检索日期、范围和筛选依据。
2. 先盘点当前实际可用的网页工具、学术数据库连接、MCP 和本地资料。本项目随插件提供 `scholarly-metadata` MCP：`search_openalex` 和 `search_crossref` 用于发现候选文献，`lookup_crossref_doi` 用于核对 DOI 书目信息。只有当工具已成功连接时才把它列为本次实际使用工具；否则使用可用的网页检索和原始页面，并说明回退。学科数据库和官方数据平台按选题需要选择，不预设已经安装。
3. 根据本次方向、限制和工具清单，填写 [Agent 提示词模板](references/agent-prompts.md)，启动文献检索 Agent 与独立来源核验 Agent。若运行环境不支持子 Agent，按这两个独立角色顺序执行并保留各自输出，不把角色设定冒充实际并行运行。

## 运行

- 文献检索 Agent 找到与问题最接近的实证或理论研究，记录可追溯的题目、作者、年份、DOI/原文链接、研究对象、数据、方法、主要发现和与拟议问题的重合程度。它须主动检索相邻术语和更窄的变量组合。
- 核验 Agent 不直接接受检索摘要为事实；可先用 Crossref 元数据核对 DOI、题名、作者和发表信息，再独立打开出版商页面或论文原文检查研究内容，用官方数据来源检查指标含义。元数据匹配不等于论文结论被核实；Crossref 未收录也不等于论文不存在。主动寻找可能已经回答候选问题的研究。对每项标记“通过／需修改／无法确认”，附证据链接与具体问题。
- 主 Agent 将“需修改”和“无法确认”的问题交回检索 Agent 定向补检，再交核验 Agent 复核。对关键问题至少完成一轮核验；补检直到关键陈述有足够证据，或明确列出未解决项。不要声称进行了实际未执行的轮次。
- 主 Agent 形成候选研究空白，说明与最接近研究相比的新问题、数据与方法可行性、仍需查重的边界。将横截面关联与因果效应区分开。

## 交付

给使用者：本次输入与检索边界、实际使用的工具/MCP、文献对照表、核验记录、候选研究空白及其证据、未确认事项和下一步建议。文献表中每条论文都应有可打开的原始来源；不得编造 DOI、研究结论、数据集或检索轮次。
